# Virtual Gaming Revenue & User Analysis Dashboard

## 📊 Project Overview

An interactive Virtual Gaming Dashboard developed using Microsoft Excel to analyze gaming revenue, user activity, gender distribution, state-wise revenue, and daily user trends.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

## 📌 Key KPIs

- Total Revenue: 797,777
- Average Users/Day: 499.67
- Average Revenue/User: 53.22

## 📈 Dashboard Features

- Top 5 States by Revenue
- Average Active Users Per Day
- Revenue by Gender
- Daily User Activity
- State-wise Revenue Analysis
- Gender Analysis

## 🎛️ Interactive Filters

- Gender
- State
- Date

## 💡 Key Insights

The dashboard provides an overview of gaming revenue and user engagement across different states, genders, and dates.

It helps identify high-revenue states, analyze active users over time, and compare revenue generated by different customer groups.
